# @uitaste/skill

The agent skill [uitaste](https://github.com/uitaste/uitaste) installs into your project (`.claude/skills/uitaste/`, `.cursor/rules/uitaste.mdc`): `SKILL.md` plus reference files for tokens, lint rules, composition and the critique rubric.

Install it with `npx uitaste init`. Docs: https://github.com/uitaste/uitaste
