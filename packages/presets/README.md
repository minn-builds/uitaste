# @uitaste/presets

The four curated [uitaste](https://github.com/uitaste/uitaste) presets: editorial, swiss, soft-utility and brutal. Each folder holds `preset.json` (token seeds), `rules.md` (composition rules for the agent) and `examples/` (Hero, Pricing, DashboardCard).

Used by `npx uitaste init --preset <id>`. Docs and previews: https://github.com/uitaste/uitaste
